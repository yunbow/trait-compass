# セルフチェック設問の参考資料一覧

このページは、[self-check-methodology.md](./self-check-methodology.md) §1 で述べている
「開発者が事実確認(ファクトチェック)を行いながら整理してきた」設問の元データについて、
**カテゴリ単位で実際に参照した公的資料・学術論文を一覧化したもの**です。

## この一覧の位置づけ・限界

- 設問文自体は、開発者が管理する非公開の事実確認済みデータセット(242件、1件ごとに
  当事者視点・出典・確認日を記録)をもとに、本アプリ用の体験頻度アンケート文へ
  書き改めたものです。このデータセット自体は本リポジトリの範囲外のため公開していません。
- 以下の一覧は、そのデータセットの各項目(カテゴリ内の1件ごとの記録)が出典として
  参照していた公的機関ページ・学術論文を、**カテゴリ単位で集計・重複排除したもの**です。
  242問1問ずつを個別の文献に対応づけるものではありません。
- これらの資料は、各カテゴリで扱う特性・体験の**一般的な傾向を説明するもの**であり、
  本アプリの30問のセルフチェック(固定サブセット)そのものの信頼性・妥当性を検証した
  研究ではありません。臨床的妥当性・標準化が無いことは
  [self-check-methodology.md](./self-check-methodology.md) §1/§5 のとおりです。
- 「二次資料」は厚生労働省・国立障害者リハビリテーションセンター等が発信する解説ページ、
  「一次資料(学術論文)」は学会誌等に掲載された個別の研究論文を指します。
- 掲載URLは2026-08時点でリンク疎通を確認しました。ファクトチェック時点(2026-05-30)は
  `e-healthnet.mhlw.go.jp` だった3件のうち、「不安症 / 不安障害」は2025年3月の移管先
  (`kennet.mhlw.go.jp`)で同一記事を確認できたため新URLに差し替え、ASD/ADHDの解説記事2件は
  移管先に相当ページが見当たらなかったため、同一カテゴリに残る `hattatsu.go.jp`(発達障害情報の
  ポータルサイト)の資料と重複することもあり削除しました。
